## 6. 방안 비교 (보고만 · 고치지 않음)

### 6-1. 어류 DE·EF·LE·TU — 양식 `종명(개체수)` ↔ 관리자 정수

사실:
- 양식 44~47행 라벨은 `기형(deformity) DE 종명(개체수)` 등이지만, **같은 양식의 43행 `=SUM(Q44:Q47)` 은 숫자만 더한다** → 글자(`붕어(2)`)를 넣으면 엑셀 자체의 비정상개체수·M8 도 0 으로 계산된다. 라벨과 양식 수식이 서로 어긋나 있다.
- 관리자: `DECount` 등 `int?` · 정수가 아니면 `형변환실패`(저장 막힘). FAI M8 은 네 칸 정수 합.
- 조사자 앱: 입력칸이 자유 글자 · 계산은 정수만(글자면 0) · 내보낼 때 글자를 그대로 쓴다 → 조사자가 `붕어(2)` 로 적으면 **관리자 Import 에서 막힌다**.
- 현재 자료: 최종본·게시 DB 모두 0건(전부 빈칸).

| 방안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A. 정수로 통일**(권장) | 관리자 그대로. 양식 라벨을 `개체수(정수)` 로 바로잡고(발주처 합의), 종명은 비고(30행)에 적게 안내. 조사자 앱 입력칸을 정수만 받게 | 양식 SUM 수식·관리자·조사자 계산이 모두 같은 값 · 관리자 코드 변경 0 | 어느 종이 비정상인지는 비고에만 남는다 · 양식 문구 수정에 발주처 합의 필요 · 조사자 앱 수정(별건) |

### 6-2. 조류 번호 입력 변환표

사실:
- 관리자 조류는 날씨 외 **변환표가 없다** — 대항목(U)·세부항목(V)·서식유형(W)은 글자 그대로 저장, 번호를 쓰면 번호가 저장된다. 게시 DB `HabitatType='3'` 1건.
- 양식 U3 대항목 번호(`8) 연안 … 10) 산림 … 12) 인공초지`)와 V3 세부항목 설명의 번호(`8) 자연초지 … 10) 연안 … 12) 산림`)가 **서로 다르다**. W3 `2) 번식추축` 은 오타(DB 실값은 `번식추측`).
- 게시 DB 대항목 실값에는 양식 목록에 없는 이름도 많다(`기타` 638 · `육수` 565 · `농경지` 271 · `해수` 114 · `경작지` 59).
- 조사자 앱: 도래유형만 코드(RES/SV/WV/PM)로 내보내고, 대항목·서식유형은 자유 글자.

| 방안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A. 변환표 추가**(권장 · 번호 기준 확인 뒤) | 다른 분류군처럼 대항목(U3 1~12)·서식유형(W3 1~6, `번식추측`) 번호 → 이름. 글자는 그대로 | 양식대로 번호를 써도 이름으로 저장 · 기존 패턴 그대로 | U3/V3 번호 불일치 — 어느 쪽이 맞는지 발주처 확인 필요 · 세부항목은 자유 글자라 대상 아님 |
| B. 번호를 검수 오류로 | 숫자만 있는 값은 `목록없음` 으로 막아 이름으로 고치게 | 추측 변환이 없음 | 번호로 적은 과거 파일은 재등록 때 막힘 |
| C. 그대로 | 조사자 앱은 이름을 쓰므로 손으로 채운 양식만 문제 | 변경 없음 | DB `'3'` 1건 같은 값이 계속 생길 수 있음 |

### 6-3. 관찰형 날씨 `비` / `비(눈)`

사실:
- 관찰형 3종 양식 D3 은 `맑음, 흐림, 비`(글자), 전치형 4종 양식은 `1 맑음, 2 흐림, 3 비(눈)`. 관리자 변환표는 7개 모두 `3 → 비(눈)`, 글자 `비` 는 `비` 로 저장 → 같은 날씨가 두 값으로 갈린다.
- 조사자 앱은 `맑음/흐림/비(눈)` 만 쓴다. 게시 DB 에 비 기록 0건(영향 0).

| 방안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A. 관리자에서 `비` → `비(눈)`**(권장) | 날씨 변환에서 글자 `비`(필요하면 `눈`)도 `비(눈)` 으로 | 저장값 하나 · 조사자 앱·전치형 양식과 같음 · 작은 수정(7개 VM 의 같은 자리) | 원문 글자를 바꿈(그래도 의미는 같음) |
| B. 변환표 3번을 `비` 로 | | 관찰형 양식 글자와 같음 | 전치형 4종 양식·조사자 앱(`비(눈)`)과 어긋남 — 비권장 |
| C. 저장은 그대로, 조회·통계에서 같게 취급 | | 자료 변경 없음 | 조회 화면마다 처리 필요 · 빠뜨리기 쉬움 |
| (함께) 양식 문구 | 관찰형 D3 을 `맑음, 흐림, 비(눈)` 으로 | 근본 해결 | 발주처 양식 수정 |
