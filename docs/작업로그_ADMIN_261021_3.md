### 2-2. 문구 한 곳 — `Helpers\BenthosSubstrateNote.cs`(새 파일)

- `MovedText(bedrock, concrete)` — 0보다 큰 칸만 적어 `하상 암반 10% · 콘크리트 5%(지침 저서 하상 6칸 밖 · 옮김)` / `하상 콘크리트 7%(…)` / 둘 다 없으면 `null`.
- `AppendTo(note, text)` — Note 가 비면(공백만 포함) 문구만, 있으면 `"{note} / {text}"`.
- 정리 SQL 이 같은 문구를 만든다(주석에 서로 가리킴). 조사자 v0.4.1 `MoveRockConcreteToNote` 와도 같은 문구다.

**일괄등록**(`BulkBenthosControlViewModel.DataValidation`) — 칸별 검수(종전 정수 변환 그대로) 뒤에 한 번: 문구를 Note 끝에 붙이고 `Bedrock`·`Concrete` = NULL. 옮긴 기록 수를 돌려받아 `SubstrateMovedCount` 로 —
결과 창('변환된 자료' 줄) · 가져오기 알림 `하상 암반·콘크리트 값 n건을 특이사항으로 옮겼습니다(지침 저서 하상 6칸 밖)` · 저장 알림 끝 `· 하상 암반·콘크리트 → 특이사항 n건`. 저장 단추 조건은 바꾸지 않았다(막지 않음).

### 2-3. 편집기(`ViewModels\Editors\BenthosEditorControlViewModel.cs`)

- VM 의 `Bedrock`·`Concrete` 속성을 없앴다(화면에 칸이 없으므로).
- 기록을 열 때(`EditModelToProperty`): `Note = AppendTo(EditModel.Note, MovedText(EditModel.Bedrock, EditModel.Concrete))`. **`EditModel` 은 건드리지 않는다** → [닫기]만 하면 DB 는 그대로.
- 안내 줄 `SubstrateNotice` — 옮겼으면 빨간 글씨 `하상 암반 10% · 콘크리트 5%(…) → 특이사항 끝에 옮겼습니다. [저장]해야 반영됩니다`, 아니면 기본 안내(보통 글씨).
- [저장](신규 · 수정): `Bedrock = null`, `Concrete = null`.

### 2-4. 정리 SQL · 안내 글

- `tools\sql\benthos_bedrock_concrete_to_note_261021.sql` — `BEGIN TRANSACTION` → **전** SELECT(저서_전체 · 옮길_기록 · 값_남음 · 옮김_표시) → ① `Bedrock > 0 OR Concrete > 0` 행 Note 끝에 문구 → `changes()` → ② 값이 남은 행(0 포함) 두 칸 NULL → `changes()` → **후** SELECT → `COMMIT`.
